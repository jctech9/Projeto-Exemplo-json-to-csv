ANTES DE EXECUTAR O PROJETO, É PRECISO ESTAR LOGADO NO SISTEMA DE GESTAO DE RISCOS

OS COMANDOS ABAIXO SÃO PARA WINDOWS 

1. INICIAR SERVIDOR NO WINDOWS- dentro da pasta do projeto demo execute: no powwershell
   .\mvnw spring-boot:run

2. EXPORTAR DADOS REMOTOS (API)
   
  2.1. EXPORTAR VIA API PASSANDO ID
    curl -X POST "http://localhost:8080/export/xlsx/api" -H "Content-Type: application/json" -d "{\"id\": 63}" -o "saida.xlsx"

-------------REQUISIÇÃO VIA URL-----------------
http://localhost:8080/export/xlsx/api?id=76

3. EXPORTAR VIA PAYLOAD DIRETO
  curl -X POST "http://localhost:8080/export/xlsx" -H "Content-Type: application/json" -d "{\"content\":[{\"id\":1,\"nome\":\"Processo A\"}]}" -o "saida-payload.xlsx"
